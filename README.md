# KBIHU Nahdatul Jamaah

Landing page company profile untuk KBIHU Nahdatul Jamaah.

## Stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Vercel-ready

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy ke Vercel

Push repository ini ke GitHub, lalu import repository tersebut di Vercel.

No environment variables are required for the current static landing page.
